## 1. 用户目标与第一版边界

### 1.1 原始诉求

客户希望在网页模拟一个可 360° 连续旋转的有质量的单杆摆。设定角度后可自然下落。摆杆连接有质量的水平滑块，水平驱动力有上限，滑块沿有限导轨移动。需要自动从自然下垂、完全静止状态起摆并保持竖直向上，扰动后能够稳定恢复。可修改杆长、质量、滑块质量、配重位置、执行器能力等参数，观察不同被控对象控制难度。未来可扩展一个关节形成二阶倒立摆，但首版不实现二阶。

### 1.2 产品应具备的可见能力

- 在浏览器打开和授权一个本地工作目录，加载历史和预设，显示文件有效性与使用权限。
- 自由运动：设置初始状态，按物理方程计算重力下落及振荡，不以预设动画伪装。
- 手动控制：键盘方向键/网页按钮按住施加水平力、松开归零，失焦自动释放。
- 自动控制：从 `θ=+π rad, x=0, dx/dt=0, dθ/dt=0` 开始确定性起摆→切换稳摆→位置回中→可重新起摆。
- 参数调整：杆、配重、车、导轨、摩擦、执行器、控制算法及验收阈值分组编辑，单位与合法性校验。
- 运行工具栏：开始、暂停、继续、终止、重置、倍速、减速、单步（默认 1ms 物理步）；暂停时调整控制器参数可保留物理状态，但修改结构/质量要初始化实验。
- 实时二维动画、等比例坐标、配重/质心、安全区、可开关受力与速度矢量、轨迹、机械能；曲线支持缩放、显隐、历史时间点与峰值保留。
- 实验评价：首次稳定、额外 20s 耐久、两种扰动、请求力与实际力/饱和/超速、失败与异常原因分类。
- 真实文件化：完整的已采样时序、事件、状态快照、诊断、图表和 PDF 报告位于用户选择目录；目录可复制备份、重新打开、恢复查看。
- 中文默认、英文切换、SI 单位不随语言改变。

### 1.3 明确不做

- 移动端适配和 30 FPS 验收（ADR-178 延后 ADR-081、084、106、107、110、123、124、175 相关移动部分）。
- Firefox/Safari 的完整本地工作目录读写。首版 Chrome 和 Edge 桌面。
- 服务器端物理计算、本地辅助文件服务、云端实验数据库/自动同步、IndexedDB/OPFS 实验存储。
- 完整电机电气系统、传动机构间隙、静摩擦锁止/粘滑、真实传感器与噪声、车体/杆碰撞。
- 真实硬件安全认证；仿真结果不得直接作为真实运动控制装置可用的证明。

## 2. 平台与运行

- **技术架构**：纯浏览器本地物理和控制计算，使用与主 UI 隔离的 Worker 等执行环境；渲染与物理时间独立（ADR-082、095）。可以采用维护良好的前端技术，但未要求固定具体框架或语言；实现决策应形成设计说明。
- **启动**：同时支持 HTTPS 静态站和可信 `localhost` 静态资源服务；两种来源使用相同工作区文件格式，权限不可假定跨来源共享（ADR-179）。
- **授权**：每次使用时需由用户明确选择工作目录并获得权限；所有用户实验数据和过程产物都写入此目录。必须处理取消选择、权限丢失、只读、目录损坏、格式不兼容。
- **离线**：允许首次加载后缓存静态应用资源以离线打开，但**不**允许缓存实验数据至内部持久化数据库；权限和目录访问仍须按浏览器规则授权。
- **浏览器**：正式 Chrome/Edge 桌面；参考性能设备候选 Win11、Core i5-1240P、16 GB、1920×1080；实际型号及浏览器版本验收前锁定。
- **后台**：标签不可见/后台暂停仿真物理时间，恢复页面后用户显式继续；不得按墙钟时间追赶补算（ADR-093）。
- **性能**：标准完整负载至少 60s，桌面 60FPS 候选目标，≥95% 帧时长约 ≤16.7ms；物理与现实时间的比值另记；性能不达标不得跳步或暗改数值模型。

## 3. 工作目录和文件持久化：最高优先级的工程约束

### 3.1 工作区生命周期

`未选择 → 选择/授权 → 校验工作区 → 校验独占 → 只读或读写 → 实验运行/历史查看 → 释放`。异常或锁状态不确定不得误判可用。

- 空目录可授权后初始化；有合法工作区标志可加载；含无关文件且没有合法工作区标志的非空目录不得自动初始化或修改（ADR-184）。
- 无写权限但有读权限时，可进入只读状态、查看有效历史，不得开始任何要求记录的实验（ADR-180）。
- **ADR-182 严格单实例**：同一物理目录被其他任意网页实例使用时，第二实例**连工作区只读打开也禁止**。此规则优先于允许只读的 ADR-180；不同物理目录可并行。
- 必须覆盖同源多标签、Chrome↔Edge、HTTPS↔localhost、同时争抢、异常关闭/重启、不同路径指向同物理目录等场景。严格互斥**当前未验证**，同源 Web Locks 不足以证明跨来源/浏览器互斥。P0 不通过即按 ADR-183 停止阶段准入、提交证据、提出受控变更，不能自行允许并发。

### 3.2 建议目录契约（需按版本正式冻结）

```text
pendulum-workspace/
  workspace.json                  # 身份、格式版本及工作区状态
  presets/                        # 版本化公共基准与简单/标准/困难、用户自定义工况
  experiments/<experiment-id>/
    manifest.json                 # 权威实验文件清单、提交/封存状态
    config.json                   # 不可变完整实验配置快照
    samples/chunk-000001.csv      # 有界分块的高频原始样本
    events/part-000001.jsonl      # 结构化事件、时刻与序号
    result.json                   # 首次成功/耐久/扰动/异常结论
    charts/                       # 按来源版本生成的图片
    reports/                      # PDF报告等衍生版本
    diagnostics/                  # 异常、检查记录
  index/                           # 可从manifest重建的摘要索引
  validation/                      # 测试与验收证据
  backups/                         # 用户发起的备份
  tmp/                             # 未提交过程文件
```

**所有**过程文件都必须在用户所选工作区内，非工作区目录不得自动落盘。用户明确导出到其他位置时可以通过用户交互另行选择。

### 3.3 文件格式与关键字段

- 文件统一 UTF-8 和显式 `schema_version`。JSON/JSONL 对字段类型、数值范围、版本与引用关系严格校验；导入内容不能执行代码。
- `workspace.json`：工作区身份 ID、schema 版本、应用兼容范围、初始化与迁移状态。身份 ID 并不能替代跨进程互斥证明。
- `config.json`：已展开的完整物理参数、初始状态、控制器版本/参数、积分/控制/采样周期、扰动和验收规则及运行环境，创建后不因用户修改预设而改变。
- `samples/*.csv`：固定字段及 SI 单位、严格递增的样本序号与 `sim_time_s`、车位置/速度、连续角/规范化角/角速度、请求力与实际力、外力与外力矩、控制模式/阶段、必要能量与状态。建议保留完整精度，不使用界面格式覆盖数值；所有已配置采样周期的样本持久化。
- `events/*.jsonl`：事件序号、事件类型、输入载荷、仿真生效时间与上下文；包括模式切换、扰动、控制器调整、限幅、触边、稳定、异常、暂停与恢复。
- `manifest.json`：每个已提交数据块的路径、序号/时间范围、记录数、长度、校验摘要及封存状态；与 `result.json`、`config.json` 交叉引用。历史索引并不是权威来源，可重新生成（ADR-188）。
- `result.json`：分别记录首次稳定、20s耐久、抑扰成功、失稳恢复、失败/阻塞/异常、正式验收资格及对应的固定规则版本。
- 图表和 PDF 可以根据同一原始快照重新生成，但应另存版本；不可静默改写已封存原始实验数据（ADR-189）。

### 3.4 批量写入、封存与异常恢复

- 默认采样 10ms，可选 1ms、100ms；控制器默认 10ms，物理积分默认 1ms。采样密度与渲染频率不同；未要求强制保存每一个物理步。
- 采用**有界分块**，先创建临时文件、完成写入并关闭、校验其内容和序号，再将文件引用发布到清单；已经提交的块不可原地修改（ADR-186）。
- **禁止声称多文件原子事务天然存在**。必须针对清单更新、分块写入和断电/崩溃设计实际恢复验证。中断后最后已提交记录可查看；未提交文件不得被标记为有效时间序列。绝不填造缺失样本。
- 数据库格式旧决策已由 ADR-177/181 替代；禁止通过 IndexedDB 或 OPFS 暗中建立备用实验数据库或索引。
- 无法可靠写入、权限撤销、容量不足：冻结需完整记录的实验，保留最后可确认完整的数据与诊断；只读不允许新实验。
- 历史文件损坏：仅标记受影响实验不可验证，不删除有效历史，不以插值覆盖原始数据。封存结果和原规则版本长期保留。
- 迁移和备份：先保留可恢复旧版本，新格式完整校验后才切换。用户能直接复制整个目录进行备份；需要显式控制覆盖与恢复。

### 3.5 需要规格审查决定但不能由 Agent 假称已确认的内容

- 正式列名、分块大小、提交间隔、JSON schema 精确字段、事件同刻优先级、跨文件引用更新顺序、锁恢复安全判据、可接受磁盘使用量。
- Agent 可提出带理由的**建议及备选**，并在用户批准后纳入带版本的详细设计；无法获得独占的核心能力，不允许凭建议绕过 ADR-182。

## 4. 动力学模型与符号规范

### 4.1 基本模型

- 平面刚体、滑块一维沿轨道中心运动，杆为均匀细刚性杆，另有位置可变的点质量配重；车体、杆质量均非零。
- 坐标 x 向右、y 向上；杆从竖直向上开始 θ=0，逆时针正；下垂 +π；内部连续累计角，控制误差按最短等价角计算。
- 配重在转轴到杆端 0～L 内调节，改变整体质心和转动惯量；配重移动只允许在准备/重新初始化工况时变更，默认模型中不计算运行中的配重驱动动力学。
- 导轨总长指滑块**中心**有效行程，视觉车体宽度不额外扣除；触边准确定位后停止，不模拟杆与轨道或车体碰撞反弹。
- 摩擦：滑块库仑幅值加低速平滑近似、滑块粘性阻尼、关节粘性阻尼；零阻力实验必须支持。
- 外部短时水平力和关节力矩作为动力学外力、力矩，不在首版增加关节驱动电机；完整记录做功和耗散。
- 自由运动的**精确静止平衡点**必须忠实保留：若初态摆杆恰好竖直向上或竖直向下且没有扰动/控制输入，理想模型不会自动离开平衡点；展示“初始角度后自然下落”时，应让用户显式选择非平衡初态或明确施加物理扰动，绝不注入隐藏随机初扰。自动模式从 +π 主动起摆是另一项独立要求。

### 4.2 执行器

- 控制输入为期望水平力，执行器输出为**实际**水平力。
- 每物理步应用最大驱动力、最大滑块速度方向限制及机械功率上限；驱动、制动均遵守绝对机械功率约束。
- 在静止 v=0 时仍能施加最大允许推力，不应出现以功率除速度的除零错误。
- 达到速度上限后不再主动使其超速；外力/耦合引起的超速不能强制截断状态，须记录并使正式控制验收未通过。
- 力饱和与超速必须记录请求力、实际力、限制原因和持续时间。

### 4.3 参数范围与默认值（候选，未验证）

**标准**：杆长0.5m、杆质量0.2kg、滑块质量1.0kg、配重0.05kg@0.5L、轨道总长2m、力20N、速度2m/s、机械功率40W。

**简单**：杆长0.35m、杆质量0.12kg、滑块质量0.6kg、配重0.02kg@0.5L、轨道3m、力35N、速度2.5m/s、机械功率80W。

**困难**：杆长0.8m、杆质量0.4kg、滑块质量1.5kg、配重0.12kg@0.75L、轨道1.4m、力12N、速度1.5m/s、机械功率18W。

公共默认：g=9.81m/s²；滑块库仑摩擦0.2N；粘性0.1N·s/m；关节0.002N·m·s/rad；安全缓冲区默认0.10m；物理步长1ms、控制周期10ms、记录周期10ms。

允许范围：杆长0.2～1.2m，杆质量0.05～1kg，滑块0.3～5kg，配重0～0.30kg，导轨0.8～5m，力2～100N，速度0.5～5m/s，功率5～250W，重力0～20m/s²，库仑摩擦0～5N，滑块粘性0～5N·s/m，关节粘性0～0.1N·m·s/rad。非法值必须拒绝并解释；不要自动截断为合法值。

三档工况采用版本化公共基准＋覆盖差异；每次运行时展开成完整不可变配置，包含其他默认参数及控制器版本。不同难度并**不保证**一定可控。

## 5. 控制器与运行状态

### 5.1 三种模式

- `free`：按方程自由运动。
- `manual`：左右按钮或方向键按住施力，松开归零；页面失焦、切标签、离开手动模式、输入框抢占键盘时释放所有持续手动输入。
- `auto`：确定性主动起摆、滞回进入稳摆、满足角度+角速度条件后切换。稳摆同时约束摆杆竖直和滑块居中；失稳且未触边时按规则重新起摆。

模式切换在控制周期边界生效，保留当前物理状态，重置/初始化对应控制器内部状态。控制输入采用零阶保持；执行器每个物理步重新计算约束。

### 5.2 控制算法契约

- 必须有固定版本、初始化、输入状态、周期更新、请求力输出、诊断、状态序列化/恢复（用于稳定快照）和受控 reset。
- 首版优先考虑能量法起摆、LQR稳摆，但**未证明指定参数与控制律会达标**；需在验证阶段整定并冻结控制器增益和切换阈值。
- 从精确竖直下垂、完全静止初态必须由控制器主动产生确定性输入，不得秘密加随机初扰。
- 控制器异常或单次计算超过明确预算必须冻结实验并输出诊断；整体设备慢于实时只显示运行倍率，不按控制器异常处理。
- 标准验收仅适用冻结工况、控制器版本、规则版本、初始状态，且中途未改参数的实验；用户探索实验仍可展示结果但不能冒充官方达标。

## 6. 物理求解、事件、数据时钟

- 固定物理时间步长与独立控制更新周期（默认1ms/10ms）。可用精度适合的固定步积分方法；ADR 规定了固定步与测试，**未强制已确认某个特定积分算法名称**。应在详细设计说明选型、误差与单步边界处理。
- 所有实验控制限时、稳定持续、扰动脉冲、恢复及耐久用**仿真物理时间**；真实耗时与渲染FPS单独记录。后台暂停或人为暂停时仿真时间不推进。
- 事件时间轴和同刻优先级必须明确、可复现；规范化角与累计角分开保存；绘图刷新不能决定采样时刻。
- 支持暂停、单步1ms、变速；不得为保持画面速度丢弃数值步。
- 无耗散基准机械能收支应满足正确守恒；势能零点在自然下垂位置，数值能量残差需要非零参考尺度，零能量附近使用绝对误差。

## 7. 正式控制验收规范（全部候选目标）

### 7.1 首次稳定

标准初态：`θ=+π rad`，`x=0`，`cart_v=0`，`theta_dot=0`。

同时满足：

1. 摆角误差绝对值≤3°；
2. 摆角速度绝对值≤0.2rad/s；
3. 滑块中心位置偏差绝对值≤0.10m；
4. 滑块速度绝对值≤0.10m/s；

并连续保持5秒。从自动控制启动至完整5秒判定结束的仿真时间：简单≤30秒，标准≤60秒，困难候选≤120秒（困难不作强制成功要求）。

### 7.2 稳摆耐久与扰动

- 首次稳摆成功后追加独立无扰动**20秒**耐久考核，四条件持续满足且不触边、不出现控制异常。短时离开阈值则该耐久项不通过，但保留首次稳摆记录。
- 水平扰动：本工况最大执行器驱动力的10%，持续0.1秒；关节力矩扰动：0.1N·m，持续0.1秒。
- 两种测试从等价的已验证完整稳摆快照（含控制器内部状态）**分别独立**开始；无合格快照时标记阻塞，不能用伪造稳定状态代替。
- 全程未出阈值记“抑扰成功”；若失稳则需从脉冲结束起**10秒内重新完成连续5秒**四条件，记“失稳恢复成功”，不能只记录首次进入范围。

### 7.3 次数与结果分类

简单、标准分别开展：默认起摆、水平外力、关节力矩，每项独立重复3次（2×3×3=**18次基础控制测试**），全部通过。20秒耐久测试另外单列。

结果不可压为单个永久成功：记录首次稳定、耐久、扰动类别、后续失稳/恢复、边界超限、异常和结束状态；必须区分 `未执行 / 阻塞 / 通过 / 失败 / 无效`。

正式验收禁止边界触碰、执行器超速、控制异常或数据不完整；困难工况如实报告探索性结果。

## 8. 物理正确性与确定性验收（候选）

- 物理基准至少含平衡位置、自然下落、自由摆动、无耗散能量守恒、阻尼耗散、移动配重质量分布、受力与功率约束、外力矩及外力、轨道步内触边。
- 光滑无控制基准场景10秒：1ms与0.5ms步长比较，摆角差≤0.1°、车位差≤1mm（未验证）。
- 无摩擦无驱动30秒：参考非零能量的机械能漂移最大≤0.1%（未验证）。
- 同版本同运行环境、相同配置与时间标记输入，车位置、车速度、摆角、角速度的绝对误差候选各≤10⁻⁶（分别以对应 SI 单位计），关键事件时间差≤1ms（未验证）。
- 参数校验严格，包括数值有限性、范围、组合关系、配重位置与轨道安全区。仿真出现 NaN/∞ 或非法内部状态时冻结，保留最后有效状态及异常诊断。

## 9. UI、图表、数据导出和报告

- 工程实验台：中心二维动画，左侧可收起参数，右/下曲线、指标；运行工具栏始终可操作。
- 仿真图：有尺寸刻度、车/轨/摆杆/关节/配重/质心、安全区；高级矢量、轨迹、能量可切换；等比例缩放和平移，视图操作不改变物理状态。
- 允许在实验未开始/重置状态拖动摆杆设置初始角度和车位置，运行中不可直接拖动而绕过方程；手动扰动必须作为力或力矩。
- 记录原始高频数据，历史曲线按视图分辨率降采样时保留分段最小/最大值、关键事件；任何正式计算基于未改写原始采样数据。
- 支持 CSV/JSON 结构化导出、PDF完整实验报告和图表图片；PDF需含原始配置/模型/控制版本、曲线、性能、扰动、异常和“候选/已验证”状态。PDF及图表必须与同一实验配置及数据快照绑定。
- 历史实验清单显示工况、起始时间、完成/中断/封存状态、首次成功/耐久/扰动结果、不可验证原因及版本。

## 10. P0 风险优先级和实现阶段闸门

**P0-WKS（前置优先）— 文件授权和单目录单实例**

- 空目录、已有工作区、无关文件目录、只读权限、权限撤销、同源双标签、跨 Chrome/Edge、跨 HTTPS/localhost、同时争抢、异常退出重入。
- **结果必须有真实浏览器与磁盘证据**，仅理论 API 推断不合格；任何跨来源严格独占未证明都视为阻塞。

**P0-IO — 文件持久化和恢复**

- 每一分块均校验样本数、序列、时间、校验摘要；模拟写到一半关闭、发布清单期间关闭、断电、满盘、只读、手动改文件、丢失索引、迁移失败。
- 必须能明确识别已提交、未提交、封存与不可验证，不得静默改写/补造数据。

**P0-PHY — 动力学与数值正确性**

- 先在隔离于 UI 的测试环境用可审计物理场景完成第 8 节验证；不通过不能声称模型物理可靠。

**P0-CTL — 真实可达性与控制验收**

- 控制器参数经验证整定且冻结后，执行第7节标准18次基础控制及独立20秒耐久，保留失败和限制证据；不能为成功改工况。

**P1 — 页面集成、输出和性能**

- 完成中文/英文 UI、CSV/JSON/PDF、图形及高频数据、离线更新、静态部署和60FPS候选性能验收。
