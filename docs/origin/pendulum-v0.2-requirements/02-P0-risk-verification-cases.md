# 一阶倒立摆仿真系统 — P0 风险验证用例集（需求级）

- 文档编号：TEST-P0-001
- 版本：V0.2 候选详规 / 2026-11-01
- 范围：ADR-001～190；特别关注 ADR-177～190
- 状态：**全部未执行**；本文件规定将来应验证什么，不包含可运行程序、测试脚本或已通过结果

## 1. 验证纪律与结果格式

每项用例必须保留：用例 ID、关联 ADR/REQ、受测软件和浏览器版本、操作系统、物理工作目录标识、输入文件摘要、前置条件、精确操作、期待结果、实际结果、日志/截图/目录清单和散列证据、执行日期、执行人、通过/失败/阻塞判定。

- `通过`：按规定输入得到要求的客观结果，并有完整证据。
- `失败`：可执行但违反预期，无权擅自降低门槛。
- `阻塞`：依赖条件未满足或权限/能力限制，不能当通过。
- `未执行`：没有开展试验。
- 部分结果达到不等于总体通过；例如同源锁通过不代表跨 Chrome/Edge、跨 HTTPS/localhost 独占成功。

## 2. P0-WKS — 工作目录准入和独占（关联 ADR-177～184）

### P0-WKS-01 首次选择及目录合法性
- 前置：准备空目录、有效工作区、包含无关文件的非空目录各一个。
- 动作：分别通过 Chrome/Edge 选取；测试取消授权、只读目录。
- 期待：空目录可在授权后安全初始化；有效工作区加载；无工作区标识的非空目录不自动覆盖无关文件；只读状态禁止新实验。
- 证据：初始化前后目录树、文件摘要、UI 状态、权限记录。

### P0-WKS-02 同源双标签互斥
- 前置：同一 HTTPS origin 的两个标签，均选择同一工作区。
- 期待：仅一个实例取得工作区访问权；第二实例不得读取完整工作区/启动实验/写入，提示占用。注意这比“仅允许一个写入者”更严格。
- 证据：页面状态、日志、工作目录元数据。

### P0-WKS-03 Chrome/Edge 跨浏览器互斥
- 前置：同一物理目录，两款桌面浏览器并发选择，重复双向取得顺序及同时竞争。
- 期待：任何时刻只有一个实例可打开整个工作区，失败实例不修改目录。
- 证据：两个进程并行时间线、目录散列、异常日志。

### P0-WKS-04 HTTPS 与 localhost 跨来源互斥
- 前置：同一工作目录，分别用线上 HTTPS 静态站及 localhost 本地静态服务打开，两方向及同时竞争。
- 期待：严格满足 ADR-182；**仅同源 Web Locks 通过不足以判定本项通过**。
- 证据：来源 URL（不得包含敏感查询信息）、页面操作时间线、文件结果。

### P0-WKS-05 崩溃与遗留占用恢复
- 前置：第一实例已打开工作区且执行写入。
- 动作：强制关闭页面/浏览器，随后尝试重新打开；重复有/无未提交文件两种情形。
- 期待：不存在同时成功的两个实例；异常退出后有明确、安全、可审计的恢复路径；不能错误接管仍活跃的实例。
- 证据：过程录制、恢复前后文件清单、冲突报告。

### P0-WKS-06 不同工作目录并行
- 前置：两个实例分别选取两个不同物理目录。
- 期待：不因全局误锁而互相阻塞；任何操作都不跨越本次授权工作目录。
- 证据：两个目录各自的实验清单及日志。

**P0 阻断判据：** WKS-02～05 任何一项无法满足，ADR-182 的可行性尚未证实；根据 ADR-183 形成风险证据并提交受控设计决策，不能宣称工作区独占已达标。

## 3. P0-IO — 分块文件、异常和数据完整性（ADR-102、113～115、125、149、167～170、181、185～190）

### P0-IO-01 默认与高频记录
- 工况：候选测试负载包括 10 ms 采样运行 60 秒（约 6000 个采样时刻）和 1 ms 采样运行 60 秒（约 60000 个采样时刻）；只作为测试负载建议，不是新增业务采样指标。
- 期待：清单、序号、时间范围、样本数与所有已提交 CSV 分块一致；无序号重叠/无未解释缺口；可导出、再次打开和校验。
- 证据：CSV 记录数、清单校验、重新打开后的图表数据对比。

### P0-IO-02 未提交分块期间强制关闭
- 动作：在临时文件写入、文件关闭、清单更新等多个切点分别制造中断。
- 期待：已提交数据不回退，未提交部分不得宣称有效；孤儿文件被标识但不擅自覆盖有效分块；实验标记中断或不完整。
- 证据：关闭前后清单修订、数据块摘要、诊断。

### P0-IO-03 授权撤回/目录只读/磁盘空间不足
- 动作：运行中导致写入失败、拒绝或空间不足。
- 期待：根据 ADR-103、167 冻结需完整记录的实验，保留最后已提交部分并清晰报告，绝不偷偷转 IndexedDB/OPFS。
- 证据：系统错误类别、最后提交时间、目录变化。

### P0-IO-04 用户手动损坏、删除或修改文件
- 动作：分别更改已封存 CSV、JSONL、manifest 或 PDF，删除一个已列入清单的块。
- 期待：原始数据变化可检测；被影响实验被标记不可验证；无关历史仍可读取；不插值伪造原始样本。
- 证据：更改前后散列及受影响实验列表。

### P0-IO-05 历史索引丢失和重建
- 动作：删除可重建索引（非权威实验文件），重新打开目录。
- 期待：由权威 manifest 重建；已封存数据及原验收版本不变。
- 证据：索引重建日志与同一实验清单对比。

### P0-IO-06 配置与报告快照一致性
- 动作：完成实验后修改当前预设，再重新生成 PDF/CSV/图片。
- 期待：导出基于原实验的不可变 config、result 和样本/事件；新报告另存版本，原验收证据不被覆盖。
- 证据：两个版本的配置关联和原文件散列。

### P0-IO-07 备份、迁移和失败回退
- 动作：完整备份；模拟迁移中断、文件损坏、版本不兼容、恢复失败。
- 期待：原数据可恢复；半迁移状态不激活；失败不能覆盖唯一有效副本；历史验收结果保持原版本。
- 证据：恢复前后数量、散列、版本关联与故障日志。

## 4. P0-PHY — 物理模型及数值正确性（ADR-003～006、020、047、055、066～070、120～129、139、148、152～156）

### P0-PHY-01 平衡点与自由运动
- 输入：规范化坐标、无外部控制/阻尼的静止平衡、若干自由下落场景。
- 期待：平衡点符合动力学、重力方向和正负号正确，角度可连续多圈，角速度状态连续。

### P0-PHY-02 移动配重与能量账本
- 输入：不同合法配重位置，分别施加零阻尼、有阻尼、外力和外力矩。
- 期待：质心/惯量与参数一致；能量收支区分执行器做功、外力及力矩做功、摩擦与阻尼耗散。

### P0-PHY-03 时间步长收敛
- 输入：确定的光滑、无控制基准场景，积分时间 10 秒，步长 1 ms 对比 0.5 ms。
- 候选通过：摆角差 ≤0.1°、滑块位置差 ≤1 mm，必须在指定测试场景、数值口径下实际验证；有控制切换场景另比较性能指标。

### P0-PHY-04 无耗散能量漂移
- 输入：定义非零参考能量尺度的无外力无阻力场景，30 秒。
- 候选通过：最大相对能量偏差 ≤0.1%。

### P0-PHY-05 执行器与导轨
- 输入：施加不同请求力、近零速度、达到速度上限、外部扰动和轨道边界穿越。
- 期待：请求力与实际力分开；每物理步检查力/速/功率约束；外致超速保留连续状态且正式验收视为未通过；精确定位触边事件，立即结束无反弹。

## 5. P0-CTL — 标准起摆、稳摆及扰动（ADR-001、008、024～025、048～051、108～109、118～120、133～136、141、157～161、172～176）

### P0-CTL-01 自动起摆
- 简单、标准工况；初始角 +π rad、中心位置及全部初速度为零，控制器主动启动，不能偷偷改初态。
- 四项稳定阈值：角度误差 ≤3°、角速度 ≤0.2 rad/s、位置偏差 ≤0.10 m、滑块速度 ≤0.10 m/s，连续 5 秒。
- 完整完成时限：简单 30 秒、标准 60 秒，全部使用仿真时间。

### P0-CTL-02 连续稳摆耐久
- 首次稳定后额外无扰动连续 20 秒，四条件始终满足，不触边、不发生控制异常。

### P0-CTL-03 两种独立扰动
- 水平力：执行器最大驱动力 10%，持续 0.1 秒；摆杆纯外力矩：0.1 N·m，持续 0.1 秒。
- 两测试从同一完整稳定状态快照独立开始。
- 全程保持稳定 = **抑扰成功**；失稳则从脉冲结束起 10 秒内完成连续 5 秒四维稳定 = **失稳恢复成功**；没有有效快照则标阻塞，不得伪造通过。

### P0-CTL-04 重复验收和可复现性
- 两工况 × 三类测试 × 每类 3 次 = 18 次基础正式控制运行，全部须通过。
- 比较对齐采样的四项状态误差候选绝对容差 10^-6（各自 SI 单位）及关键事件时间误差候选 ≤1 ms，严格记录受测环境。
- 首次成功、耐久、抑扰、失稳恢复及运行结束状态分开记录；不覆盖历史。

## 6. P0 性能与交付限定（ADR-084、106～107、122、124、175、178）

- 首版仅桌面 Chrome/Edge；桌面候选硬件 Win11、Core i5-1240P、16GB、1920×1080，最终型号/版本待验收前锁定。
- 候选目标：在标准完整显示负载与默认数据采样运行至少 60 秒，≥95% 帧耗时 ≤约16.7 ms；仿真时间与现实时间倍率独立报告。
- 即使性能不足，不得自动跳过物理计算/改变步长；性能未验证时不得标“通过”。

## 7. 退出 P0 风险状态的条件

- 所有相应 P0 用例有**实际执行证据**而非理论可行性描述。
- P0-WKS 独占要求全部成立，才允许将 ADR-182 的技术可行性标为验证通过。
- 物理数值、标准控制、数据完整性分别通过各自明确基线；任何一项未通过都保留失败证据及新的受控 ADR 变更申请。
- 无法执行或缺少前置条件的用例只能为“阻塞”，不能视为成功。
