# Triage Labels

| Canonical role | Label in our tracker | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给代理自主实现 |
| ready-for-human | ready-for-human | 需要人类实现 |
| wontfix | wontfix | 不予实施 |

技能提到分诊角色时，使用对应的 Label in our tracker。
